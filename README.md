# weekly-revision-checklist

An Agent Skill that helps university students plan weekly revision and practise recall using course information they provide. It produces a short checklist and does not complete graded work.

## Folder structure

```text
weekly-revision-checklist/
├── SKILL.md
├── README.md
└── LICENSE
```

There are no scripts or external reference files; the skill's workflow is small enough to live in `SKILL.md`.

## Install

Copy the `weekly-revision-checklist` folder into the skills directory configured for your agent. The directory varies by agent host, so consult that host's documentation if you are unsure where skills are loaded from.

## Validate

Install the Agent Skills reference validator and run it against this folder:

```sh
pip install skills-ref
skills-ref validate ./weekly-revision-checklist
```

The copyright holder in `LICENSE` is a placeholder. Replace `Your Name` with the appropriate name before distributing the skill.
